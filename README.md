# ☕ Taste-Talk

A simple and modern cafeteria website built using HTML and CSS. The project provides an easy-to-use interface for browsing menu items such as coffee and tea while demonstrating fundamental web development concepts.

## 🌐 Live Demo

🔗 https://shahriar398.github.io/Taste-Talk/

---

## 📖 Overview

Taste-Talk is a front-end web development project designed to showcase a cafeteria menu through a clean and user-friendly interface. The website includes separate pages for different beverage categories and uses custom CSS for styling and layout.

---

## 🚀 Features

- Responsive and clean user interface
- Dedicated menu pages
- Coffee menu section
- Tea menu section
- Easy navigation between pages
- Custom CSS styling
- Organized project structure
- Image assets for menu presentation

---

## 🛠️ Technologies Used

- CSS3
